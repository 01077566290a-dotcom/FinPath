# FinPath 기존 타임라인 데모 (보존 문서)

사회초년생의 미래 계획을 준비 일정으로 바꾸는 금융정보 웹 MVP. 정적 mock data 기반으로 계획 입력, My Financial Timeline, 금융 의사결정 상세의 세 화면을 제공합니다.

## 실행

Node.js 22 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
```

브라우저에서 http://localhost:5173 을 엽니다. 날짜 계산 검증은 `npm test`로 실행합니다.

## 프로젝트 구조

```text
index.html                         HTML 진입점
server.mjs                         로컬 정적 파일 서버
src/
  app.js                           해시 라우팅, 화면 렌더링, 사용자 상호작용
  styles.css                       디자인 토큰, 데스크톱·모바일 레이아웃
  data/financial-decisions.js       Life Event와 financial_decisions mock 데이터
  lib/timeline.js                   날짜 검증, 개월 계산, 타임라인 생성 (순수 함수)
  lib/storage.js                    브라우저 저장 및 복원
tests/timeline.test.js              일정 계산과 상태 검증
```

## 화면과 데이터 흐름

- `#/plan`: 닉네임(선택), 입사일, 첫 월급일, 독립 예정일 입력. 날짜는 하나 이상 필요합니다. 입사일과 첫 월급일을 모두 입력하면 선후관계를 검증합니다.
- `#/timeline`: 지금 준비해야 할 항목을 먼저 표시하고, 월별 전체 일정·이벤트 필터·상태 필터·계획 요약·완료 진행률을 제공합니다.
- `#/decision/:id`: 준비 이유, 체크리스트, 생각해 볼 질문, 기준 일정, 준비 완료/취소를 제공합니다.

`financial_decisions`의 `event`가 사용자 계획의 기준 날짜를 선택하며 `offsetMonths`를 더해 시작일을 생성합니다. 예를 들어 독립일이 2027-03-15이면 -6개월인 전세·월세 비교의 준비 시작일은 2026-09-15입니다. 월말 계산은 대상 월의 말일로 보정하며 날짜는 사용자 기기의 현지 달력 기준입니다.

완료되지 않았고 시작일이 오늘 이전 또는 오늘이면 `now`, 이후면 `upcoming`, 완료한 항목은 `done`입니다. 시작일이 지난 항목도 숨기지 않습니다. 계획 수정 시 날짜를 다시 계산하고 기존 확인·완료 기록은 유지합니다. 이벤트 날짜를 지우면 해당 일정이 숨겨지며, 다시 입력하면 기록이 복원됩니다.

첫 방문에는 오늘을 기준으로 만든 예시 계획이 표시됩니다. 예시 체크는 저장되지 않으며, 실제 계획 저장 시 초기화합니다. 실제 계획과 체크 상태는 `localStorage`의 `finpath-v1`에 저장됩니다. 저장이 차단된 환경에서는 현재 방문 동안 동작하며 안내가 표시됩니다. 브라우저 데이터를 삭제하면 계획도 삭제됩니다.

## V1 범위

취업 2개, 첫 월급·자산형성 3개, 독립·전월세 4개의 일반적인 준비 콘텐츠를 포함합니다. 외부 API, 로그인, 금융상품 추천, 뉴스, 알림, 서버 데이터 저장은 없습니다. Google Fonts를 사용할 수 없으면 시스템 글꼴로 표시됩니다. 최신 Chrome, Edge, Safari, Firefox를 대상으로 합니다.

콘텐츠는 UX 검증용 초안이며 구체적인 금융상품 조건이나 실시간 제도를 다루지 않습니다. 서비스 확장 시 데이터 계층을 API로 대체하고, 상세 콘텐츠 검수·출처·갱신일을 추가할 수 있습니다.
