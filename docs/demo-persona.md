# 시연 인물: 정하은 (주거 + 비상자금)

기획안 v4의 결정 사항 #6(시연 인물과 목적 조합)에 대한 초안입니다. 화면(①~⑤), 엔진 계산, 리포트 문구가 **모두 이 한 사람의 숫자로 맞물리도록** 만들었습니다. 엔진이 완성되기 전에는 리포트 화면을 이 숫자로 먼저 만들고, 엔진이 나오면 아래 기대값과 같은지 확인하는 **정답지**로 씁니다.

> **표시 규칙**
> - **[가정]**: 팀 결정이나 출처 확인 전에 임시로 둔 값입니다. 바뀌면 이 문서의 계산도 함께 고칩니다.
> - **[C 확인]**: 콘텐츠 담당이 출처와 기준일을 확인해야 하는 항목입니다.
> - 금액 단위는 **만 원**이고, 예적금 이자는 핵심 숫자 계산에 넣지 않았습니다. 그래프에서만 적용합니다.
> - 기준 시점은 **2026년 10월**입니다. "n개월 뒤"는 2026년 10월에서 n개월이 지난 달입니다.

## 1. 이 인물을 고른 이유

| 기획안의 훅 | 정하은에게서 드러나는 장면 |
| --- | --- |
| 내가 생각한 목표 vs 실제로 필요한 돈 | "1년에 1,500만 원이면 독립할 수 있겠지" → 실제로는 **1,884만 원** 필요 |
| 부족분과 해결 방법 | 지금 계획으로는 목표 시점에 **401만 원 부족**. 해결책 3가지가 각각 다른 결과를 냄 |
| 절약 → 몇 달 앞당겨지는지 | 구독·통신비 **8만 원** 줄이면 독립이 **2개월** 빨라짐 |
| 내 숫자로 만든 진단 | 지금은 월급의 **30%**를 저축하지만, 독립하면 **7%**로 줄어듦 |
| 비상자금 먼저 | 독립 전에 비상자금을 채워야 하는 이유가 숫자로 보임 (독립 후에는 월 17만 원밖에 못 모음) |
| 지역 반영 | 마포구 월세 → 주거 모듈 지도, 지역 청년 주거 정책 |

시연 대상(입사 1~3년 차 직장인)에 정확히 들어맞고, 숫자가 극단적이지 않아 청중이 "내 얘기 같다"고 느낄 수 있는 범위로 잡았습니다.

## 4. 계산 (엔진 기대값)

### 4-1. 월 현금흐름

| | 지금 (부모님 집) | 독립 후 (마포구 월세) |
| --- | --- | --- |
| 실수령액 | 245 | 245 |
| 고정지출 | 67 | 60 |
| 주거비 (월세 + 관리비) | 0 | 68 |
| 변동 생활비 | 105 | 100 |
| **월 생활비 합계** | **172** | **228** |
| **매달 모을 수 있는 돈** | **73** | **17** |
| 저축률 | 29.8% → **약 30%** | 6.9% → **약 7%** |

### 4-2. 목적별 실제로 필요한 돈

| 목적 | 계산 | 금액 |
| --- | --- | --- |
| 비상자금 | 독립 후 월 생활비 228 × **3개월** | **684** |
| 주거 | 보증금 1,000 + 이사·초기 비용 200 − 대출 0 | **1,200** |
| **합계 (실제로 필요한 돈)** | | **1,884** |

- 비상자금 개월 수 **3개월**은 결정 #2(고용 형태별 기준)가 나오기 전 임시값입니다. **[가정] [C 확인]**
- 기준 생활비는 **독립 후** 생활비(228)를 씁니다. 비상자금이 지켜야 할 생활은 독립한 뒤의 생활이기 때문입니다. 팀에서 다르게 정하면 바꿉니다.

### 4-3. 리포트 핵심 숫자 세 개

| 핵심 숫자 | 값 | 계산 |
| --- | --- | --- |
| ① 내가 생각한 목표 | **1,500만 원** (1년) | 입력값 |
| ② 실제로 필요한 돈 | **1,884만 원** | 4-2 |
| ③ 지금 계획으로 모을 수 있는 돈 (2027년 9월까지) | **1,483만 원** | 680 + 73 × 11 |
| 차이 (②와 ③) | **401만 원 부족** | 1,884 − 1,483 |
| 지금 계획대로면 필요한 돈을 다 모으는 때 | **17개월 뒤 (2028년 3월)** | (1,884 − 680) ÷ 73 = 16.5 → 17개월 |

> 시연 포인트: ①과 ③이 **거의 같다**(1,500 vs 1,483). 정하은의 감각은 "모을 수 있는 돈"으로는 정확했지만, **필요한 돈**을 384만 원 적게 잡고 있었습니다. 비상자금을 빼먹었기 때문입니다.

### 4-4. 배분 규칙에 따른 타임라인 (결정 #3 비교용)

결정 #3(비상자금을 전부 먼저 채울지, 일부만 먼저 채울지)을 정하는 데 쓰라고 두 가지를 모두 계산했습니다.

**규칙 A: 비상자금을 전부 채운 뒤 주거에 배분** (리포트 기본값으로 가정)

| 시점 | 일어나는 일 |
| --- | --- |
| 지금 (2026.10) | 모아둔 680 → 비상자금으로 (684 중 99%) |
| 1개월 뒤 (2026.11) | 비상자금 684 **완성**, 남은 69 → 주거로 |
| 17개월 뒤 (2028.03) | 주거 1,200 **완성** → 독립 가능 |
| 독립 후 | 매달 17만 원씩 저축, 비상자금 3개월치 유지 |

**규칙 B: 비상자금을 50%(342)만 먼저 채우고 주거에 배분**

| 시점 | 일어나는 일 |
| --- | --- |
| 지금 (2026.10) | 680 중 342 → 비상자금, 338 → 주거 |
| 12개월 뒤 (2027.10) | 주거 1,200 **완성** → 독립 가능 (규칙 A보다 **5개월 빠름**) |
| 독립 직후 | 비상자금 356 (월 생활비의 **1.6개월치**만 있음) |
| 32개월 뒤 (2029.06) | 독립 후 월 17만 원으로 비상자금 684 완성. **약 20개월 동안 보호가 얇은 상태** |

> 팀 결정에 참고할 점: 규칙 B는 독립을 앞당기지만, 독립 후 저축 여력이 월 17만 원뿐이라 비상자금을 다시 채우는 데 오래 걸립니다. 정하은처럼 **독립 후 저축률이 크게 떨어지는 사람**에게는 규칙 A가 안전하다는 메시지가 됩니다.

### 4-5. 부족분 해결 방법 (기획안 ④-4)

| 해결 방법 | 내용 | 결과 |
| --- | --- | --- |
| 기간 늘리기 | 입주를 2027년 9월 → **2028년 3월**로 | 6개월 늦추면 부족분 없음 (680 + 73 × 17 = 1,921 ≥ 1,884) |
| 생활비 줄이기 | 11개월 안에 맞추려면 매달 **110만 원** 저축 필요 (지금보다 +37만 원) | (1,884 − 680) ÷ 11 = 109.5 → 110 |
| 목표 조정 | 보증금 1,000 → **500만 원** 집 | 필요한 돈 1,384 → 2027년 9월 안에 가능 (10개월 뒤, 2027년 8월). 단 월세가 오를 수 있어 독립 후 저축이 더 줄어듦 |
| (참고) 대출 활용 | 청년 대상 보증금 대출로 일부 충당 | 금액·조건은 정책 확인 후 계산 **[C 확인]** |

### 4-6. 절약 → 앞당겨지는 시간 (리포트 '아낄 수 있는 것')

기준: 지금 계획대로면 17개월 뒤(2028년 3월) 필요한 돈 1,884만 원을 다 모읍니다.

| 절약 | 매달 저축 | 필요한 개월 | 앞당겨지는 시간 | 리포트 문장 |
| --- | --- | --- | --- | --- |
| 통신비 9 → 4 (알뜰폰) | 78 | 1,204 ÷ 78 = 15.4 → 16 | **1개월** | "통신비 5만 원 줄이면 독립이 1개월 빨라져요" |
| + 구독 3개 정리 (−3) | 81 | 1,204 ÷ 81 = 14.9 → 15 | **2개월** | "구독과 통신비 8만 원 줄이면 독립이 2개월 빨라져요 (2028년 1월)" |
| + 외식·쇼핑 −20 | 101 | 1,204 ÷ 101 = 11.9 → 12 | **5개월** | "생활비 28만 원을 줄이면 2027년 10월, 원래 계획과 거의 같은 때 독립할 수 있어요" |

| --- | --- |

### 4-8. 모듈별 표시값

**비상자금 모듈 (게이지)**
- 목표: 684만 원 (독립 후 생활비 3개월치)
- 지금: 680만 원 → **99%**, "독립 후 생활비로 약 3개월 버틸 수 있어요" (680 ÷ 228 = 2.98)
- 1개월 뒤(2026년 11월) 완성 예정 (규칙 A 기준)

**주거 모듈**
- 개인화 제목: "**마포구 월세 독립까지 17개월**" (지금 계획 기준) / 절약 시 "15개월"
- 내 예산으로 가능한 범위: 보증금 1,000만 원, 월세 + 관리비 68만 원 (독립 후 저축 17만 원이 남는 상한선)
- 마포구 시세 범위와 실거래가 조회 링크 **[C 확인: 시연 지역 데이터, 결정 #5]**
- 지역 청년 주거 정책 후보: 청년 월세 지원(국토교통부·서울시), 청년 전용 보증금 대출(주택도시기금) **[C 확인: 현재 운영 여부, 조건, 공식 링크, 기준일]**

**미래 (1년 뒤 · 5년 · 10년 그래프)**
- 1년 뒤(2027년 10월): 두 계획 모두 아직 부모님 집이라 **같은 금액**입니다. 모아둔 돈 680 + 73 × 12 = **1,556만 원** (예적금 이자 제외)
- "지금처럼"과 "타임라인대로"가 갈라지는 시점은 독립하는 17개월 뒤부터입니다. 그래프는 보증금을 자산에 포함할지 엔진(A)과 정해야 합니다. 포함하면 독립 후에도 순자산이 꺾이지 않고, 빼면 독립 시점에 크게 떨어집니다.

- "마포구 월세 독립까지 **17개월**. 원래 계획한 2027년 9월보다 6개월 늦어요."
- "생각한 목표는 **1,500만 원**이었지만, 실제로 필요한 돈은 **1,884만 원**이에요. 독립 후 생활비 3개월치 비상자금 **684만 원**이 빠져 있었어요."
- "지금 모아둔 680만 원이면 비상자금은 **다음 달**에 채워져요. 그다음부터 매달 73만 원이 독립 자금으로 가요."
- "구독과 통신비 **8만 원**을 줄이면 독립이 **2개월** 빨라져요."

## 6. 시연 흐름 (약 2분)

1. **①** "1년 동안 1,500만 원"을 입력하고, 돈 상황 5가지를 채웁니다.
2. **②** 마포구를 고르고, 목적은 주거와 비상자금을 고릅니다.
3. **③** 주거 질문 4개만 나옵니다. 비상자금 질문은 이미 아는 정보라 **나오지 않습니다** ("이미 아는 건 묻지 않아요"를 말로 짚기).
4. **④** 타임라인: 비상자금이 다음 달 완성되고, 17개월 뒤 독립합니다.
5. **⑤** 리포트: **1,500 vs 1,884 vs 1,483**에서 멈추고 설명합니다. 이어서 "8만 원 줄이면 2개월"을 보여 줍니다.
6. (선택) 해결책에서 '기간 늘리기'나 '보증금 500'을 눌러 숫자가 바뀌는 걸 보여 줍니다. 기획안의 "진행할수록 바뀌는 숫자"에 해당합니다.
