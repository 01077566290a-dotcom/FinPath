# FinPath 디자인 방향: Quiet Planner

국내 금융 앱을 따라 한 느낌을 피하려고, 해외 서비스와 국내 비금융 서비스의 레이아웃을 살펴보고 우리 서비스에 맞는 것만 골랐어요. 이 문서는 무엇을 보고, 무엇을 골랐고, 어떻게 적용했는지 정리한 기록이에요.

## 1. 살펴본 서비스

| 서비스 | 분야 | 눈여겨본 점 | FinPath에 쓸 수 있나 |
| --- | --- | --- | --- |
| Linear, Vercel, Stripe | 업무 도구·개발 | 검정·회색만으로 위계를 만듦. 얇은 선, 반투명 헤더, 검정 주 버튼 | ✅ 색을 줄이는 기준 |
| Apple 제품 페이지 | 브랜드 | 벤토 그리드: 크기가 다른 칸에 장면 하나씩 | ✅ 홈에서 ①~⑤를 보여주는 방식 |
| Notion | 문서 | 따뜻한 회백색 바탕, 정돈된 글자 단계 | ✅ 바탕색과 글자 단계 |
| Airbnb | 여행 | 알약 모양 버튼·칩, 큰 둥근 카드, 넉넉한 여백 | ✅ 버튼·칩 모양 |
| Copilot Money | 해외 가계부 | 요약 먼저, 카드와 진행 막대로 상태를 한눈에, 세부는 펼쳐 보기 | ✅ 리포트 구조 (이미 v2에서 반영) |
| Wealthfront Path | 해외 재무 설계 | 숫자를 바꾸면 미래 그래프가 바로 바뀜 | ✅ 리포트의 '아끼면 빨라져요' |
| Typeform | 설문 | 한 화면에 질문 하나, 큰 글자 | ✅ 입력 화면 |
| Duolingo | 학습 | 길(path) 위의 동그라미로 순서와 진행 표시 | ✅ 타임라인 지도 (이미 중앙 줄기형) |
| Apple Fitness | 건강 | 링·게이지로 목표 달성률 | 🔸 비상자금 '몇 개월 버틸 수 있나' 게이지에 나중에 활용 |
| 당근 (SEED) | 국내 커뮤니티 | 대표색 하나 + 회색 단계, 직관적인 규칙 | ✅ 색 규칙 |
| 오늘의집, 29CM | 국내 커머스 | 큰 사진·편집 디자인 | ❌ 사진이 없는 우리 서비스와 맞지 않음 |
| 토스, 뱅크샐러드 | 국내 금융 | 큰 숫자, 파란 포인트 | ❌ 따라 한 느낌이 날 수 있어 제외 |

## 2. 고른 방향

**Quiet Planner**: 조용한 종이 위에 내 숫자만 또렷하게.

1. **색은 의미로만:** 잉크(검정·회색), 돈(초록), 부족(빨강) 세 가지뿐이에요. 파랑·청록 같은 장식 색은 없앴어요.
2. **숫자가 주인공:** 큰 숫자, 고정폭 숫자, 짧은 설명.
3. **종이 같은 카드:** 따뜻한 회백색(#f6f6f3) 바탕 위에 흰 카드를 놓고, 얇은 선과 아주 옅은 그림자를 써요.
4. **알약 버튼:** 주 버튼은 검정 하나예요. 보조 버튼은 흰 바탕에 테두리예요.
5. **글꼴:** Pretendard(오픈 라이선스). 제목은 자간을 좁혀 단단하게 보이게 했어요.
6. **움직임은 조금만:** 들어올 때 살짝 떠오르고, 카드에 마우스를 올리면 살짝 들려요. '움직임 줄이기' 설정을 켠 사람에게는 움직이지 않아요.

## 3. 적용한 것

| 화면 | 바뀐 점 |
| --- | --- |
| 공통 | 색 토큰을 새 기준에 연결, 반투명 헤더(위에 고정), 알약 버튼, 카드 모양, 진행 표시 색 |
| 홈 | 가운데 큰 문장 + 벤토 그리드. 칸마다 실제 화면의 한 장면(세 숫자 비교, 타임라인, 칩, 앞당겨지는 시간)을 보여줘요 |
| ①~③ 입력 | 큰 질문 글자, 단계 배지, 큰 입력칸, 선택지 모양. 휴대폰에서는 다음 버튼이 화면 아래에 붙어요 (CSS만 바꿨고 1번 코드는 그대로) |
| ④ 지도 | 검정 시작점, 흰 시기 배지, 단계 동그라미(지금 볼 단계는 검정, 완료는 초록), 카드 들림 효과, 자금 배분 패널 글자 키움, 리포트 안내를 검정 띠로 |
| ⑤ 리포트 | 바탕·잉크를 같은 기준으로 맞춤, 카드 모서리, 팝업 뒤 흐림 |

## 4. 되돌리기

- 모든 모양은 `app/design.css` 한 파일에 있어요. `app/layout.js`에서 `import './design.css';` 한 줄을 지우면 이전 디자인으로 돌아가요.
- 홈 화면만 새 컴포넌트(벤토 그리드)로 바꿨어요. 홈 아래 '화면 흐름'을 '이전 흐름'으로 바꾸면 예전 홈이 나와요.

## 5. 다음에 할 것

- 입력 화면: 빠른 선택 칩(기간 6개월·1년·2년), 입력한 금액 바로 읽어 주기 (1번 작업과 맞춰서)
- 리포트: 비상자금 '몇 개월 버틸 수 있나' 링 게이지 (Apple Fitness 참고)
- 발표 화면 크기에서 글자 크기 점검
